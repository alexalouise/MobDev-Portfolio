# Task Perf 1 - Mobile Portfolio App UI

An interactive Android application built using Java and XML that serves as a mobile portfolio featuring dynamic activity navigation.

---

## 📋 Overview

This project was developed as part of an academic task performance in mobile application development. The application showcases a multi-screen mobile portfolio interface where users can navigate between different pages (activities) through clickable buttons and custom UI elements.

---

## 🎯 Objectives

* Create and configure a multi-activity project in Android Studio.
* Design visually structured UI screens using standard Android XML components (`TextView`, `ImageView`, `Button`, `EditText`).
* Implement interactive `Button` click listeners in Java to switch between different screens (`Intent` navigation).
* Import and format custom graphical assets within the project's `drawable` folder.

---

## 🛠️ Tech Stack & Requirements

* **IDE:** Android Studio
* **Language:** Java & XML
* **JDK:** JDK 8+
* **Target Platform:** Android

---

## 📝 Project Features

1. **Main Portfolio Page:** Serves as the landing screen displaying profile/overview information alongside navigation options.
2. **Multi-Activity Navigation:** Clickable buttons configured with event listeners that seamlessly transition users to different pages/activities.
3. **Custom Asset Integration:** Uses drawables saved in `app/src/main/res/drawable` with optimized image scaling (`android:scaleType="fitXY"`) for responsive layouts.

---

## 💡 Conclusion

This project demonstrates foundational concepts in Android application development, specifically UI component layout design and multi-screen navigation using Java intents. By turning static wireframes into interactive pages, it provides a functional base for building full-fledged mobile portfolio applications.
